CareerAI - how to run (Windows)

ONE-TIME SETUP
1. Backend:   cd backend
              pip install -r requirements.txt
              python database/init_db.py
2. Frontend:  cd frontend
              npm install
3. Open backend\.env in Notepad and paste your YouTube API key after  YOUTUBE_API_KEY=
   (no quotes, no spaces), then save.  Test it with:  python check_youtube.py

EVERY TIME
- Double-click start_backend.bat   (or: cd backend, python app.py)
- Double-click start_frontend.bat  (or: cd frontend, npm run dev)
- Open the address Vite prints (usually http://localhost:5173)
- If the backend was running when you edited .env, restart it.

IF THE PAGES SHOW ERRORS / YOU GET LOGGED OUT
- Log out and log in again, or clear the browser's Local Storage (F12 > Application).

YOUTUBE LESSONS
- python check_youtube.py            tells you exactly what's wrong with the key
- python check_youtube.py --prefetch finds videos for all 25 topics at once
- Courses on the same topic share videos, so ~25 searches cover all 1,200 courses.
  Free quota is ~99 searches/day (resets at midnight Pacific time).
- Without a working key, only the 4 courses that ship with a video (SQL, Python, Git, Java) can play.

MODEL ACCURACY (python ml/train_model.py reproduces it; results in backend/ml/models/metrics.json)
- Model: Random Forest (100 trees) + cosine similarity. Final score = 0.6 x cosine + 0.4 x Random Forest probability.
- 20% test set (80:20 split): accuracy 90.3%, precision 89.8%, recall 90.3%, F1 89.6%, top-5 98.0%.
- Real job-posting rows only (107): accuracy 21.5%, top-5 71.0%. See metrics.json.
- Training takes 1-3 minutes. Model file is about 16 MB.
